Create a multiplayer browser game called "Case Files".

OVERVIEW

Case Files is a collaborative detective game for virtual teams.

Players work together to solve fictional workplace mysteries.

The game should be lightweight, replayable, collaborative, and suitable for virtual team engagement events.

The game must require NO AI APIs, NO OpenAI integration, NO Gemini integration, NO Anthropic integration, and NO paid services.

All content should be generated using predefined templates, randomization, clue pools, motivations, rumors, and workplace scenarios.

The goal is a fun, replayable game that runs entirely within a Replit Core plan.

====================================================
GAME FLOW
====================================================

1. Home Screen

- Start New Case
- Join Case
- Rules
- Credits

Display the tagline:

"Welcome to Case Files.
All mysteries are fictional.
All clues are fabricated.
All suspects are innocent until randomly proven guilty."

2. Lobby System

- Create Room
- Join Room using code
- 2–10 players
- Show connected players
- Host starts game

3. Case Briefing

Generate a workplace mystery.

Display:

- Case Title
- Incident Summary
- Suspect List
- Initial Evidence

4. Investigation Phase

Players vote on investigation actions.

Actions include:

- Interview Suspect
- Review Emails
- Examine Scene
- Review Security Logs
- Check Timeline
- Verify Alibi
- Search Office
- Analyze Evidence
- Review Project Tracker
- Audit Recent Changes

Each action reveals clues.

Clues can support or contradict previous information.

Some clues are genuine.

Some clues are misleading.

5. Team Discussion

Display:

- All collected evidence
- Suspects
- Timeline
- Investigation Notes

Include a team chat panel.

6. Accusation Phase

The team submits:

- Suspect
- Motive
- Method

7. Resolution Phase

Reveal:

- Correct Suspect
- Correct Motive
- Correct Method
- Investigation Summary
- Explanation of clues

====================================================
CONSENT, PRIVACY, AND SAFEGUARDS
====================================================

This game is intended for entertainment and team engagement only.

The characters are fictional.

The names are fictional workplace characters and should not be interpreted as representations of real employees.

Consent Modal

Before entering the game, show:

"This game is a fictional workplace mystery designed solely for entertainment and team engagement.
All cases, clues, rumors, suspects, and outcomes are randomly generated and do not represent real events, actions, allegations, or behaviors."

Require acknowledgment before continuing.

No Real Allegations

The game must never generate:

- Harassment scenarios
- HR complaints
- Medical issues
- Criminal allegations
- Financial fraud
- Real company incidents
- Real disciplinary matters

Safe Mystery Categories Only

Use only light workplace mysteries.

Examples:

- Missing Tracker
- Lost Presentation
- Deleted Report
- Wrong Attachment
- Spreadsheet Error
- Missing Sign-Off

Rumor Safety

Rumors must remain playful, professional, and non-defamatory.

Never imply:

- Dishonesty
- Criminal behavior
- Misconduct
- Policy violations

Footer Disclaimer

Display:

"All characters, clues, incidents, and rumors are fictional and randomly generated for entertainment purposes."

Host Controls

Host may:

- Disable Rumors
- Disable Chat
- Reset Case
- Start New Case

Privacy

Do not store:

- Personal data
- Chat history
- Case history
- Investigation history

Store session state only.
