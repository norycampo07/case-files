CASE FILES: OFFICE EDITION
MAJOR GAME REDESIGN

OVERVIEW

Transform Case Files from a detective simulator into a team engagement game.

The game should feel like:

- Kahoot
- Jackbox
- Office Gossip
- Friendly Team Competition

NOT:

- Detective Simulator
- Evidence Management System
- Audit Investigation Tool

The goal is quick understanding, workplace humor, discussion, accusations, and laughter.

A new player should understand the game within 15 seconds.

====================================================
CORE GAME FORMAT
====================================================

Tournament-based.

2–5 Teams.

1–10 Players per Team.

Host chooses:

- 1 Case
- 3 Cases (Default)
- 5 Cases
- 7 Cases
- 10 Cases

All teams receive the SAME case each round.

After each round:

- Reveal the culprit
- Explain what happened
- Update leaderboard

After the final round:

- Display winner
- Display awards
- Display tournament champion

====================================================
HOST CONTROLS
====================================================

Host controls game progression.

Host reveals:

- Case Brief
- Team Members
- Clues
- Voting
- Results

Players cannot accidentally get ahead or behind.

Everyone stays synchronized.

====================================================
CASE DESIGN RULES
====================================================

Different case families must use different clue pools.

Do not reuse the same file-access mystery pattern.

Coffee cases should not use audit logs.

Meeting cases should not use system permissions.

Presentation cases should use slide decks and versions.

Survey cases should use surveys and questionnaire logic.

Workflow cases should use workflow logic.

Each family should feel completely different.
